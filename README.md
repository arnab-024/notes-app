# 📝 Notes App

A simple notes application built with React.js that allows you to add, edit and delete notes with persistent storage.

## 🛠️ Tech Stack
- React.js
- Tailwind CSS
- Lucide React (icons)
- Vite
- Local Storage

## ✨ Features
- Add new notes with title and details
- Edit existing notes
- Delete notes
- Notes persist on page refresh using localStorage
- Sticky note UI design

## 🚀 Run Locally
git clone <your-repo-url>
cd notes-app
npm install
npm run dev
